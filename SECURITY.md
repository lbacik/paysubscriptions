# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/lbacik/paysubscriptions/security/advisories/new)
(repository **Security** tab → **Report a vulnerability**).

Include what you found, the steps or request needed to reproduce it, and the
impact you expect. You will get an acknowledgement as soon as the maintainer
can, and a fix or assessment after that. Please allow time for a fix before
disclosing the issue publicly.

## Supported versions

Only the latest release and the `main` branch receive security fixes.

## Scope

In scope: the application code in this repository, its API and OAuth2
endpoints, and the container and CI/CD configuration.

Out of scope: findings that need a compromised host, social engineering, and
automated scanner output without a demonstrated impact.
