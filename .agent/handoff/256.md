All work so far was deep exploration of the repo + API Platform 5 / Symfony 7.4 vendor internals, converging on a concrete implementation design for migrating Subscription endpoints (`/api/v1/subscriptions`) to API Platform. Key findings and settled decisions:

- Write flow with `stateOptions(entityClass)` + custom processor: Deserialize (JSON→DTO) → ValidateProvider (DTO) → ObjectMapperInputProcessor (DTO→entity) → ValidateProcessor (mapped entity, Default group) → custom processor. Output: entity→DTO via ObjectMapperOutputProcessor/Provider.
- DTO property strategy (`src/ApiResource/Subscription`, `#[Map(source: Entity, target: Entity)]` class-level like pilot):
  - `category` must be a **relation** (`?ApiResource\ExpenseCategory`) so HAL emits `_links.category` (verified in `Hal/Serializer/ItemNormalizer`: only resource-typed props become `_links`). Invalid IRIs (foreign/unknown/malformed) fail IRI resolution during deserialization → map `ItemNotFoundException`/`InvalidIdentifierException` to 422-on-`category` in `DomainExceptionTranslator`, scoped to Subscription POST/PATCH (for PATCH, only when the item itself existed, i.e. request `data` attribute non-null, so unknown-item 404s still win).
  - Input-mapping of `category` must be **skipped** (`#[Map(if: new TargetClass(DTO))]`, no transform) so no detached category entity is built (danger with `cascade: ['persist']`); output needs a transform entity→category-DTO (static, pure). Verified `filterMetadataByPropertyType` won't re-map the transformed value.
  - Direction-scoped `#[Map(if: TargetClass(...), transform: ...)]` works both ways (verified `TargetClass::__invoke` checks `$target`, `getCallable` accepts `[Class::class,'staticMethod']` array callables without container).
  - Money (`amount`, `convertedAmount`) as `?string` decimal (sprintf `%.2F` on output): needs input+output transforms (PropertyAccessor would TypeError on string↔float). DTO constraints: NotNull + Regex `^\d+(\.\d{1,2})?$` + Positive.
  - `billingCycle` as `?BillingCycle` enum: serializer handles string↔enum; invalid values → 422 automatically via `DenormalizationViolationFactory` (backed-enum exception rule). Plus `#[Assert\NotNull]`.
  - `nextPayment` as `?string` + NotNull + Regex `^\d{4}-\d{2}-\d{2}$` + Callback real-date check; transforms string↔DateTimeImmutable.
  - `pendingReview`: output-only via `#[Map(source: 'id', if: TargetClass(DTO), transform: <service>)]`; transform service implements `TransformCallableInterface` (auto-tagged `object_mapper.transform_callable`, Security-injected) computing from entity + current user.
  - `convertedCurrency`/`createdAt`/`updatedAt`/`id`: pilot read-only pattern (`writable: false` + TargetClass guard). `confirmConvertedFor`: write-only (`readable: false`, no Map needed — entity lacks the prop so both mapping directions skip it).
  - PATCH merge-patch semantics come free: provider pre-fills DTO from entity, deserializer merges onto it (`OBJECT_TO_POPULATE`), so omitted vs explicit-null is distinguishable; empty PATCH = no-op 200 (pilot parity, drift from old 422 accepted).
- Processor reads the DTO (pilot decision 7): POST builds via service (`setOwner`, resolve category or default rule, `service->add`); PATCH uses `previous_data` DTO snapshot for original currency/converted + raw JSON member set for intent, mirrors old reconcile/confirm logic, refreshes managed entity before throwing (atomicity). `DELETE` uses repository `remove`.
- Collection: custom `SubscriptionCollectionProvider` returning `ArrayPaginator` over `SubscriptionService::get()` (reuse domain sorting/filtering; scope is already by owner). Manual validation → `ValidationException` (422): `order[name|price|renewal]` single-field + asc/desc (unknown → 422), `category=<uuid>` (malformed → 422 on `category`; unknown/foreign → empty via service), page 1-based, 25/page via `paginationItemsPerPage: 25`.
- Entity: `Subscription implements UserOwned`; `category` `#[Assert\NotNull]` moves to `web` group (POST-omitted would otherwise 422 in ValidateProcessor; web form gets `validation_groups: ['Default','web']` like ExpenseCategoryType — verified SubscriptionType currently has no groups).
- Translator additions: `SubscriptionLimitReachedException` → `/problems/subscription-limit-reached` 409; new `CurrencyConflictException` → `/problems/currency-conflict` 409; `CategoryOwnershipException` → 422 on `category`; currency `InvalidArgumentException` (Subscription ops only) → 422 on convertedAmount/currency.
