## Summary

Implemented the ADR 0005 revocation routing on branch `agent/issue-195`
(commit `596d8ed`). New `src/Connection/ConnectionLifecycle.php` owns the
two operations (end Connection / revoke credentials) with pair, user,
client, single-session, and everything scopes. All seven triggers route
through it: Connected-apps disconnect ends the Connection;
`POST /revoke` revokes one session and keeps the consent (next
authorization auto-approves); the Doctrine flush listener revokes
credentials on password change and client deactivation but ends Connections
on client removal; account deletion routes through the module with hard
delete staying as the mechanism; the emergency command now revokes pending
authorization codes too. `ConsentRevoker` and `RefreshFamilyRevoker`
deleted; `RefreshTokenFamilyRepository` keeps League token storage plus its
storage-internal replay/expiry revocation; docs
(`oauth-key-rotation.md`, `api-operations.md`) updated. New
data-provided parity test over all 7 real entry points
(`tests/Controller/ConnectionLifecycleParityTest.php`, 10 tests) plus
updated `/revoke` auto-approve test in `OAuthRevocationTest`. Full suite
green: 754 tests, 5092 assertions. Two-axis code review (diff
`32b6880...HEAD`) completed; reports below.
